# Taste

## Naming Conventions
- Names exercise/homework files with bare short `qN` prefixes (`q1`, `q2`, …) — no descriptive suffix — rather than long descriptive prefixes like `homework_1_`. Confidence: 0.85
- Applies the same bare short-numbered naming to case study files (`case1`, `case2`, …) rather than long descriptive names. Confidence: 0.8
