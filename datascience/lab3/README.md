# Lab 3

Python (pandas) lab: reading the same kind of data from different file formats, plus
loading and exporting datasets.

## Structure

- `py/` — lab scripts (plus `students.R`, the R twin of `students.py`)
- `ipynb/` — the same scripts as Colab notebooks (open in Google Colab and upload the dataset when the first cell asks)
- `data/` — input datasets
- `results/` — generated output files

Scripts resolve their paths relative to their own location, so they run from any
working directory:

```
python py/netflix.py
```

## Scripts

| Script | Reads | Does |
| --- | --- | --- |
| `task.py` | `data/StudentsPerformance.csv` | Head, shape, dtypes, score means, missing values; saves `results/student_performance_copy.csv` |
| `netflix.py` | `data/netflix_titles.csv` | Head, shape, columns, missing values, Movies vs TV Shows counts, release-year range; saves `results/netflix_acquired_copy.csv` |
| `main.py` | `data/main.xlsx` | Reads `Sheet1`, prints head / info / shape and column means |
| `mainn.py` | `data/main.txt` | Reads the text dataset and prints the head |
| `marks.py` | `data/student_marks.json` | Reads the JSON dataset and prints the head |
| `astro.py` | `../spaceexploration/data/neo.csv` | Reads the NEO dataset, prints head, tail, columns, shape |
| `convert.py` | `data/main.xlsx` | Exports every sheet to TSV and writes `results/main_clean.xlsx` |
| `students.py` / `students.R` | `data/students.*` | Reads the same 12 records from CSV, TSV, TXT and Excel, compares row counts / column names, averages `Marks`, and shows the errors caused by a wrong separator or wrong sheet |

Notes:

- `py/*.py` and `ipynb/*.ipynb` are the same programs; the notebooks keep the code but replace the `__file__` paths with a Colab upload cell, so they run as-is in Colab.
- `data/students.{csv,tsv,txt,xlsx}` hold the same 12 students; the TXT is fixed width (0-12 / 12-28 / 28-36 / 36-42) and the Excel records live in the `Data` sheet, with a `Notes` sheet used to demonstrate wrong sheet selection.
- `data/main.xlsx` sheet `Sheet3` has no header row, so its TSV is exported headerless.
- `results/main_*.tsv` / `results/main_clean.xlsx` are regenerated by `convert.py`.
- `test.py` is an empty scratch file.
